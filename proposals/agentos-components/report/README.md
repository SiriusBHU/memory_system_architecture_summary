## 摘要

**总体结论**：手机正在从「人操作应用」转向「Agent 代人操作」。Agent 替用户办事，底层只做两件事：想和做；在手机上，它还要与用户正在用的应用共享同一块芯片和内存。因此 Agent OS 的系统服务只需要三项：推理服务、执行与沙箱、内存与资源，并以「Agent 会话」为统一的管理单位。记忆由各 Agent 自己持有，系统只管读取权限。

**论证链**：复杂场景与负载 → 用户体验与商业化问题 → 技术瓶颈 → 关键技术。

| 系统服务 | 体验与商业化问题 | 关键瓶颈（负载证据） |
|---|---|---|
| 推理服务 | 推理需求爆发、云端成本扛不住：重度 Agent 用户云成本每年约 79–296 美元，1000 万重度日活每年约 7.9 亿到 30 亿美元（估算）；云转端要在成本与体验之间取舍 | 长程任务 23–32K 上下文推不动；24K 时 KV 约占每 token 访存的 45%，decode 被带宽卡在约 30–42 token/秒；PIM 等新算力没有系统支持；KV 随模型结构相差可达 12 倍 |
| 执行与沙箱 | 要做 MCP 与 A2A，先要有系统级权限管控；没有它，应用不开放接口，GUI 路线被 150 余款应用拒绝，交易类任务做不了 | 每天约 200 次工具调用，约 6% 不可逆或外发；读入内容 70%–100% 来自第三方；静态权限判定不了单次调用与入站读取 |
| 内存与资源 | 加不了内存（DRAM 合约价约为 2024 年的 4 倍），Agent 叠加在应用之上，冷启动、切回卡顿、后台被杀一起恶化 | 峰值时 Agent 侧驻留 5.2GB，12GB 机型缺约 1.2GB；模型内存未纳入记账；MoE 专家命中率需约 80% 才能达到 20 token/秒 |

**业界进展**：平台已具备「模型级」能力：Android 17 NPU Manager 提供模型加载准入与卸载式抢占；Apple AFM 3 把 20B 稀疏模型存放于闪存，按请求换入专家。长上下文、按调用的权限判定、模型内存记账在量产端侧系统中普遍缺失；PIM 的系统软件仍是空白，而 PIM 已列入自研芯片规划。2027 年是窗口期。

**架构的核心**：把 Agent 会话作为操作系统的一等对象，三项系统服务之间遵守四条约定：档位统一计算；标签全链路一致；内存统一记账；跨服务以事件协同。执行沙箱复用安全体系的身份、密钥与证明，只新建执行管控层。

**关键技术（13 项）**：

| 系统服务 | 关键技术 | 代表性目标（建议值） |
|---|---|---|
| 推理服务 | Agent 超长序列推理的优化 | 工具返回追加后首 token ≤1.5 秒；24K 上下文 decode ≥35 token/秒；精确引用 token 保留 100% |
| | LPDDR-PIM、NPU、UFS-PIM 异构融合计算 | NPU 与 GPU 协同 ≥1.3 倍；PIM 路径 3B decode ≥100 token/秒（仿真或样片）；UFS-PIM 完成预研 |
| | 硬件亲和的模型架构寻优（与模型团队联合） | 候选底座每 token KV ≤35KiB；32K 的 KV ≤1.1GiB；候选 100% 提供 NPU 实测 |
| 执行与沙箱 | 会话级隔离与状态底座 | 进程级实例 ≤50 毫秒；会话切回 ≤1 秒；内存压力下任务状态丢失 0 次 |
| | MCP / A2A 调用的权限判定与数据标签 | 判定 P99 ≤1 毫秒；需确认的调用 ≤6%；入站身份核验 100%，返回数据 100% 带标签 |
| | 出口代理与凭证托管 | 出网 100% 经代理（含 DNS）；凭证进入沙箱 0 次 |
| 内存与资源 · 通用内存管理优化 | 会话级记账与 memcg 水线自适应 | 模型内存可归属比例 ≥95%；12GB 峰值下前台应用与交互会话零回收 |
| | 系统服务与常驻进程的主动回收 | 待机时段常驻服务内存降低 ≥0.8GB（估算）；误回收率 ≤10% |
| | 匿名页冷热识别与预取换出（2027 立项 KT1） | 叠加场景冷启动 −15%～−30%；后台存活 +30%～+80% |
| 内存与资源 · 推理服务内存管理 | KV Cache 生命周期管理与前缀缓存命中率提升 | 前缀命中率 ≥90%；命中时首 token ≤0.3 秒；缓存错用 0 次 |
| | KV Cache 分页与冷热分层管理 | 停放会话 KV ≤1 秒恢复；停放 KV 压缩 ≥2.5 倍；闪存写入 ≤5GB/天 |
| | 模型加载 IO 零拷贝优化（2027 立项 KT3） | NPU 路径额外拷贝 0 份；冷加载达到闪存顺序读的 60%–70% |
| | MoE 专家命中率提升（2027 立项 KT2-A） | 逐 token 路由命中率稳态 ≥85%；同容量较 LRU 提升 ≥30% |

**投入与路线**：2027 年分四个阶段推进：一季度基线与可观测，二季度机制原型，三季度联动集成，四季度全天回放与交付。投入只计新建部分：会话级调度（其他团队）、安全体系（复用）、记忆本体（Agent 层）不计入。人力与预算待定，见第四部分。
