## 摘要

**总体结论**：手机正在从「人操作应用」转向「Agent 代人操作」。现有操作系统的四大部件（调度、进程隔离、文件系统、虚拟内存）都是为「人 + 应用」设计的。Agent OS 需要将它们重构为推理服务、执行沙箱、记忆服务、内存管理四个系统组件，并以「Agent 会话」为统一的管理单位。

**四个组件的必要性**：

| 组件 | 对应的经典部件 | 必要性（负载证据） |
|---|---|---|
| 推理服务 | 调度器 | 复用与不复用前缀，全天 prefill 量相差 7–10 倍。前台首 token ≤1 秒只有在前缀命中时才能稳定达到。Android 17 对后台应用进程设 4GiB 上限，只有系统推理服务豁免 |
| 执行沙箱 | 进程隔离 | Agent 每天约 200 次工具调用，约 6% 不可逆或外发；读入内容 70%–100% 来自第三方。长程任务每天切走切回 3–6 次，需在 1 秒内恢复，而手机上没有会话级快照 |
| 记忆服务 | 文件系统 | 每天新增约 39 条记忆，约 31 条来自不可信内容。冲突消解在现有方法中普遍失效（多跳不超过约 7%）。用户每天只能承受 2–3 次授权弹窗，而访问判定约 75 次 |
| 内存管理 | 虚拟内存 | 峰值时 Agent 侧驻留 5.2GB，12GB 机型缺约 1.2GB。KV 换出恢复 0.2–0.9 秒，重算 6–14 秒，而现有机制只能终止进程。模型内存未纳入 LMKD 与 memcg 的记账 |

**业界进展**：平台已具备「模型级」能力：

- Android 17 NPU Manager 提供模型加载准入与卸载式抢占；
- Apple AFM 3 把 20B 稀疏模型存放于闪存，按请求换入专家。

「会话级」的调度、隔离、记忆治理与内存分层，云端与学术已证明可行，但尚无任何量产端侧系统实现。这是 2027 年的窗口期。

**架构的核心**：把 Agent 会话作为操作系统的一等对象，四个组件之间遵守四条约定：

1. 档位统一计算；
2. 标签全链路一致；
3. 内存统一记账；
4. 跨组件以事件协同。

内存管理分为两个模块：

- **通用内存管理优化**：Agent 与应用共存，涉及系统服务、memcg、匿名页预取；
- **模型内存管理**：Agent 内部的 KV、专家与权重。

**关键技术（15 项）**：

| 组件 | 关键技术 | 代表性目标（建议值） |
|---|---|---|
| 推理服务 | 会话级调度与抢占 | 有后台负载时前台首 token P95 ≤1 秒；抢占时延 ≤50 毫秒；抢占不丢 KV |
| | KV / 前缀复用与多适配器驻留 | 共享前缀命中率 ≥90%；命中时首 token ≤0.3 秒；适配器切换 ≤200 毫秒 |
| | 端云协同路由 | 带隐私标签的数据违规出端 0 次；端侧承接 ≥80% 的请求 |
| 执行沙箱 | 会话级隔离与状态底座 | 进程级实例 ≤50 毫秒；会话切回 ≤1 秒；内存压力下任务状态丢失 0 次 |
| | 策略引擎与数据标签 | 判定 P99 ≤1 毫秒；需确认的调用 ≤6%；注入路径 100% 拦截或升档 |
| | 出口代理与凭证托管 | 出网 100% 经代理（含 DNS）；凭证进入沙箱 0 次 |
| 记忆服务 | 端侧分层记忆存储与检索 | 3 年规模下检索 P95 ≤150 毫秒；常驻 ≤0.3GB |
| | 记忆写入治理 | 来源标签覆盖 100%；不可信写入 100% 进入隔离区；删除级联 100% |
| | 系统级个人语义索引与授权 | 用户授权弹窗 ≤3 次/天；撤销 ≤1 秒生效 |
| 内存管理 · 通用内存管理优化 | 会话级记账与 memcg 水线自适应 | 模型内存可归属比例 ≥95%；12GB 峰值下前台应用与交互会话零回收 |
| | 系统服务与常驻进程的主动回收 | 待机时段常驻服务内存降低 ≥0.8GB（估算）；误回收率 ≤10% |
| | 匿名页冷热识别与预取换出（2027 立项 KT1） | 叠加场景冷启动 −15%～−30%；后台存活 +30%～+80% |
| 内存管理 · 模型内存管理 | KV 分页与冷热分代管理 | 停放会话 KV ≤1 秒恢复；停放 KV 压缩 ≥2.5 倍；闪存写入 ≤5GB/天 |
| | 专家与权重工作集管理（2027 立项 KT2-A） | 同容量下专家命中率较 LRU 提升 ≥30%；decode 较 mmap 基线 ≥1.5 倍 |
| | 模型加载 IO 与零拷贝（2027 立项 KT3） | NPU 路径额外拷贝 0 份；冷加载达到闪存顺序读的 60%–70% |

**投入与路线**：2027 年分四个阶段推进：一季度基线与可观测，二季度机制原型，三季度联动集成，四季度全天回放与交付。人力与预算待定，见第四部分。
