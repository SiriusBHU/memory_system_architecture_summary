## 讲述主线

1. **洞察**：先讲商业化趋势（Agent 处于爆发期），再讲技术趋势（端侧运行需要的三个趋势）；业界在往哪走；Agent 只需推理与执行两项底层能力，加上与应用共存，系统服务收为三项；业界在三项上做到了哪一步。
2. **场景与负载**：用「贴身秘书」这一个参考负载量化需求。每个领域按「复杂场景与负载 → 用户体验与商业化问题 → 技术瓶颈」展开。
3. **架构与关键技术**：用「会话」这一个对象把三项系统服务串起来；记忆留在 Agent 层，读取经 System Agent 的 MCP / A2A 接口、由沙箱判定；每个瓶颈对应一项关键技术。
4. **规划与投入**：为什么是现在、如何安排、需要多少投入；投入只计新建部分。

## 构建方式

```
cd /d/projects/ppt_templates && uv run python <本目录>/build.py --preview
```

- **`pages.py`**：各类页面的生成函数，包括 kt_page、arch_page、load_page、ux_page 和瓶颈页部件；
- **`lib.py`**：绘图原语与配色；
- **`p*.py`**：各页内容，按汇报顺序登记在 `build.py` 的 `MODULES` 中。
