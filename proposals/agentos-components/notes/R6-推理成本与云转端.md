# R6 推理需求、云端成本与云转端

> 日期：2026-11-09。用途：支撑汇报「推理的用户体验与商业化问题」一页。本模块不写关键技术。
> 已读本地材料：M4（云转端部分）、M1、`report/2-场景与负载瓶颈.md` 的 2.2.2。网络预算：WebFetch 10 次、WebSearch 4 次，均已用完；未核实项见第 6 节。
> 等级说明：官方 / 论文同行评审 / 预印本 / 厂商自报 / 二手 / 估算。

## 1. 结论摘要

1. 需求在爆发：Google 称 2026-05 每月处理约 3200 万亿 token（3.2 quadrillion），一年前（2025-05）约 480 万亿，约 7 倍（厂商自报）；折合约 107 万亿 token/天。
2. 国内同量级：字节称豆包大模型家族 2026-06 日均调用超 180 万亿 token，一年内增长超 10 倍（厂商自报，含免费 C 端流量，非计费 token）。
3. Agent 比对话耗 token 多一个量级：Anthropic 自报 Agent 约为对话的 4 倍、多 Agent 约 15 倍；本仓库参考负载不复用前缀时输入:输出约 62:1（全天）。
4. 「单价在降」这条不能直接讲：Google 官方价目表显示 2.5 Flash-Lite 输入/输出 0.10/0.40 美元每百万 token，较新的 3.5 Flash-Lite 为 0.30/2.50，且 gemini-3.6/3.8-flash 将于 2027-01-01 起、gemini-4 将于 2026-12-01 起涨价约 1 倍（官方，抓取于 2026-11-09）。「便宜模型更便宜、好模型不降反升」更接近事实。
5. 单用户成本估算（本节 3，估算）：参考负载每天约 100 万输入 + 1.6 万输出，按中档云价（0.75/3.75 美元每百万）约 0.81 美元/天、约 296 美元/年；1000 万日活约 30 亿美元/年；前缀缓存全命中口径下降到约 7.9 亿美元/年。
6. 豆包 C 端日均算力成本为千万元级，日收入不足百万元（二手，未核实原文）：说明免费 C 端 Agent 的云成本不可持续，这是云转端的商业动因。
7. 业界没有公开的「端侧承接比例」：Apple、Google、三星、高通均未给出；学术上 Intelligence per Watt 估计本地小模型可答的查询占比从 2023 年 23.2% 升到 2025 年 71.3%（预印本，单轮对话为主，不含 Agent 长任务）。
8. 云转端的代价：端侧每 token 能效比批处理服务器差约 3 倍（M4 引 2026 论文）；本地加速器 Intelligence per Watt 至少比云加速器低 1.4 倍（预印本）；功耗不能当卖点，卖点只能是成本、隐私、离线、时延确定性。

## 3. 单用户成本估算

### 3.1 假设

1. 负载取自 2.2.2 的参考负载（一个重度 Agent 用户一天）：
   - 不复用前缀：累计输入 100 万 token，输出 1.6 万 token。
   - 复用前缀与 KV：增量 prefill 约 12 万（取 9–14 万中值），其余约 88 万作为缓存命中输入，输出同为 1.6 万。
2. 不含：记忆写入额外 4–9 万 prefill、推理模型的隐藏 thinking token、多模态输入、缓存存储费（Gemini 缓存每小时按存储计费，未计入）。这些都会使成本偏高。
3. 三档云价取自第 2 节官方价目表，单位美元每百万 token（输入 / 缓存输入 / 输出）：
   - 低档：Gemini 2.5 Flash-Lite，0.10 / 0.01 / 0.40。
   - 中档：Gemini 3.6 Flash，0.75 / 0.075 / 3.75。
   - 高档：Gemini 3.1 Pro Preview，2.00 / 0.20 / 12.00。
4. 365 天、日活 1000 万，且每个日活都是参考负载的重度用户。真实用户平均强度显著低于该负载，所以 1000 万日活的数字应读作「重度用户上限」，按平均强度折算需乘以实际渗透系数。
5. 缓存命中口径是理想情况：命中率取 88%，且云侧缓存不过期。

### 3.2 结果（估算）

| 档位 | 口径 | 每用户每天 | 每用户每年 | 1000 万日活每年 |
|---|---|---|---|---|
| 低档 | 不复用前缀 | 0.106 美元 | 约 39 美元 | 约 3.9 亿美元 |
| 低档 | 前缀缓存命中 | 0.027 美元 | 约 9.9 美元 | 约 0.99 亿美元 |
| 中档 | 不复用前缀 | 0.81 美元 | 约 296 美元 | 约 29.6 亿美元 |
| 中档 | 前缀缓存命中 | 0.216 美元 | 约 78.8 美元 | 约 7.9 亿美元 |
| 高档 | 不复用前缀 | 2.19 美元 | 约 800 美元 | 约 80 亿美元 |
| 高档 | 前缀缓存命中 | 0.608 美元 | 约 222 美元 | 约 22.2 亿美元 |

计算方法（中档、不复用为例）：1.0 × 0.75 + 0.016 × 3.75 = 0.81 美元。

敏感性：
- 中档按 2027-01-01 起的新价（1.50 / 0.15 / 7.50）：不复用约 1.62 美元/天、约 591 美元/年、1000 万日活约 59 亿美元/年；缓存命中约 0.43 美元/天、约 158 美元/年、1000 万日活约 15.8 亿美元/年。
- 缓存的价值：中低档上缓存把成本降到 25–27%，说明系统级前缀缓存与 KV 复用本身就是成本杠杆，与云转端互不替代。
- 价格口径差一个量级：DeepSeek V4.1 Flash 峰值价（0.30 / 0.006 / 1.20）接近低档，国内可选价格普遍低于 Gemini 中档；国内厂商的实际成本区间应取国内价重算，这里没有做。

### 3.3 解读

- 对重度 Agent 用户，云成本在每年几十美元到几百美元之间；对一个 3000–5000 元手机的用户，年云成本占到终端价格的百分之几到百分之十几，不能被硬件毛利或订阅费轻易吸收。
- 反方向的口径：对平均用户（每天少量对话），成本低一到两个量级；因此商业化问题只出现在「Agent 常驻、任务量大」的重度用户上，这是汇报时需要说清楚的前提。
- 豆包 2 亿日活、日算力成本数千万元（二手）折算约 0.1–0.5 元每用户每天，与本节「平均用户成本低一到两个量级」方向一致，但来源未核实，只作旁证。

## 4. 云转端的收益与风险表

|---|---|---|---|
| 云端成本 | 端侧承接的 token 不再付云价；3.2 节重度用户中档约 296 美元/年（不复用）、约 79 美元/年（缓存命中）；高通称生成式搜索单次成本约为传统搜索的 10 倍 | 云价在涨而非降（3.6/3.8 Flash、gemini-4 2026-12 至 2027-01 涨约 1 倍），承接比例越高收益越大，但端侧硬件与内存要常驻成本 | [6][9]，3.2 节估算 |
| 可承接比例 | 本地小模型可答的查询占比 2023→2025 从 23.2% 升至 71.3%（单轮对话） | Agent 长任务（23–32K 上下文、25 次调用）质量差距未量化；没有公开的 Agent 端侧承接比例 | [8]；仓库 2.2.2 |

| 功耗与发热 | 无 | 端侧每 token 能效约比服务器差 3 倍（论文，口径待核实）；本地 IPW 至少低 1.4 倍（预印本）；估算 1500 token decode 约 0.28 Wh、约占 5000 mAh 电池 1.5%，prefill 未计 | M4；[8]；两个数字口径不同，只能做量级判断 |

| 隐私与合规 | 数据本地处理，对国内备案与出境更友好 | 端云混合时路由本身要看数据，需要端侧分类器或规则 | M1；待核实具体法规表述 |
| 商业模式 | 基础功能可免费（三星称基础功能永久免费、约占 90% 使用量，来源低可信），重度功能做 Pro 档 | 云端 Agent 竞品（OpenAI dot、Grok Bot、Meta Muse）体验更强且每个 Agent 一台云电脑，成本更高但能力不受端侧约束 | [10]；M1 |
| 业界做法 | Google 用 PREFER_ON_DEVICE 回落云端；Apple 端侧 AFM 3 加 PCC；阶跃「简单本地、复杂云端」 | 各家都不公开承接比例，也没有公开的端云切换阈值 | M1、M4；[8] 仅作学术旁证 |

## 5. 与其他模块的边界

- 本模块只提供「为什么要做」的商业与成本证据，不涉及 R1–R5 的关键技术。
- 前缀缓存的成本价值（3.2 节：缓存使中低档成本降到 25–27%）可作为 R5「前缀缓存与 KV 生命周期」的商业动因引用，但端侧前缀命中率、失效与侧信道归 R5。
- 端侧能效与 prefill/decode 速度的细节归 R1（长序列推理）与 R2（异构融合），本模块只引用其结论。
- 端云路由决策与仿真评估（S1）归 M4 对应课题，本模块不展开。
