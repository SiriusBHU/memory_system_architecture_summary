# G2 Agent 使用量的宏观增长曲线

> 日期：2026-11-10。预算：WebFetch 10/10、WebSearch 4/4，已用完。未核实项：9 项（见第 4 节）。
> 等级：官方 / 厂商自报 / 媒体 / 二手 / 估算。本文只写事实与出处，不含汇报措辞。多数二手页面由抓取工具摘要，未逐字核对原文。

## 1. 结论摘要

1. Google 全产品月 token：2024-04 约 9.7 万亿 → 2025-05 约 480 万亿 → 2026-05 约 3200 万亿，共 5 个点（厂商自报，经媒体转述；2026-05 点已由 2026-05-19 的 I/O 报道复核）。
2. Google 第一方模型 API 的 token 速率有完整季度序列：2025-Q3 约 70 亿/分钟 → 2026-Q3（2026-10-28）近 320 亿/分钟，同比超 4 倍、环比 +40%（后一点为官方，前四点为二手）。这条是 API 口径，与月 token 口径不同，不可混画。
3. 豆包日均 token 有 6 个点（2024-05 至 2026-06，约 1200 亿 → 180 万亿），厂商自报；2026-06 之后（2026 下半年）未检索到新数据点。
4. Agent 专属指标最强的一项是支付宝 AI 支付：累计 3 亿笔（2026-05-26，官方发布），约 90% 来自千问（媒体）；只有一个确切时间点，无公开时间序列。
5. OpenRouter 只拿到单点（2026 年 3 月第三周全球周 token 20.4 万亿，媒体转引），无历史序列，不能画曲线。
6. 反面证据：Google API 环比增速 60% → 37% → 40%，没有持续放缓；未见留存差、付费转化低的一手数据。支付宝 AI 支付高度集中于阿里自家入口（媒体）。MCP、A2A、企业 Agent 部署数、GenAI 手机出货预测均未检到可用数据。

## 3. 可画曲线的时间序列

### 曲线 A：Google 每月 token（全产品，口径一致，5 点，厂商自报，经二手转述）

| 日期 | 万亿 token/月 |
|---|---|
| 2024-04 | 9.7 |
| 2025-05 | 480 |
| 2025-07 | 980 |
| 2025-10 | 1300 |
| 2026-05 | 3200 |

注：2026-05 之后无同口径新点；2026-Q3 财报改报 API 速率，不可接续本曲线。相邻点间隔不均（最长 2024-04 至 2025-05 为 13 个月），画图用对数轴并标注间隔。月增量：2025-07 至 2025-10 约 107 万亿/月；2025-10 至 2026-05 约 271 万亿/月。

### 曲线 B：Google 第一方 API 速率（口径一致，5 点，前 4 点二手，末点官方）

| 财报季 / 日期 | 亿 token/分钟 |
|---|---|
| Q3 2025（2025-10） | 70 |
| Q4 2025（2026-02） | 100（"超过"） |
| Q1 2026（2026-04） | 160（"超过"） |
| Q2 2026（2026-07） | 220（"约"） |
| Q3 2026（2026-10-28） | 320（"近"） |

环比增长（据取整值推算）：Q4 约 +43%、Q1 约 +60%、Q2 约 +37%、Q3 +40%（官方）。上面各点均为"超过 / 约 / 近"的取整表述。

### 曲线 C：豆包日均 token（口径基本一致，6 点，厂商自报，经媒体转述）

| 日期 | 万亿 token/日 |
|---|---|
| 2024-05 | 约 0.12（推算） |
| 2025-06 | 16.4 |
| 2025-09 末 | 30 |
| 2026-01 初（约） | 60 |
| 2026-03 | 120 |
| 2026-06 | 180 |

注：2024-05 点由媒体按倍数反推；2025-06、2025-09 两点仅见于搜索摘要。2025-06 至 2026-06 为 16.4 → 180，约 11 倍，与官方"一年增逾 10 倍"相符。2026-06 之后无数据。口径为"日均 token 调用量"，含免费 C 端流量，不是计费 token。

### 不能画的曲线

- OpenRouter 周 token：仅 2026-03 一个点。
- 支付宝 AI 支付：仅 2026-05-26 一个披露点，加一个倒推点，不足 5 点。
- MCP、A2A：无数据。
