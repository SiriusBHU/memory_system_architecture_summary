# 调研 prompt：Agent 商业化趋势（增长曲线）

> 日期：2026-11-10。用途：支撑汇报第一部分新增的概括页「Agent 是否处于爆发期」。
> 本文件可直接交给子 Agent 或其他模型使用。整体模式：执行全部模块；单模块模式：只执行指定的 G1 或 G2。

## 背景

我们在准备一份面向领导的 2027 年 Agent OS 投入汇报。第一部分「洞察」的第一页要回答：**Agent 的使用是否处于爆发状态，有没有数据趋势可以论证？**
观点预设为「Agent 处于增长期或爆发期，市场广阔」，但必须用可核实的数据支撑；数据不支持时要如实写出。
页面上会画一到两条增长曲线（日活、周活、订阅数、调用量、token 用量等），所以需要**带日期的时间序列点**，而不是单个数字。

## 通用规则

1. 网络预算：每个模块最多 10 次 WebFetch、4 次 WebSearch。优先抓取下列已知页面，再搜索补缺。
2. 每条数据标注等级：官方（公司公告、财报、官方博客、官方发布会实录）/ 厂商自报（高管口头披露、经媒体转述）/ 媒体 / 二手（分析师、博客转述）/ 估算。
3. 每条数据必须写清：日期、数值、单位、口径（日活 / 周活 / 月活 / 付费订阅 / 调用次数 / token）、来源 URL。口径不同的数字不要混在一条曲线里。
4. 找不到公开的日活数据时，直接写「未见公开数据」，不要推算后当作事实。可以给出替代指标（例如母产品的周活、订阅数、token 用量），并说明为什么它能或不能代表 Agent 的增长。
5. 只写事实与出处，不写汇报措辞；不写关键技术。
6. 不在请求中携带任何个人信息。

## 模块 G1：三款 Agent 产品的用户与使用量增长

产品：OpenAI dot（2026-09 上线，随 ChatGPT Pro 提供，每个 dot 一台云端电脑）、xAI Grok Bot（2026-08-11 公测，200 美元/月）、阶跃 Step AOS（搭载于 STEPX Neo 手机，2026-07 亮相，3999 元，含 12 个月 Token Plan）。

问题：

1. **OpenAI dot**：有无公开的用户数、等待名单人数、任务量、使用时长？若没有，ChatGPT 的周活 / 付费订阅时间序列（2024 至 2026，至少 5 个点），以及 ChatGPT agent / Operator / Codex 等 Agent 功能的使用量披露。
2. **xAI Grok Bot**：有无公开的订阅数或使用量？若没有，Grok 的月活 / 日活时间序列，以及 xAI 对 Agent 用量的披露。
3. **阶跃 Step AOS / STEPX Neo**：销量、预订量、激活量、日活、日均 token 调用量、接入的服务数随时间的变化；阶跃自身披露的 Agent 或终端合作数据（如合作手机、汽车、IoT 设备的出货或调用量）。
4. **同类补充**（每项最多一条，有就写）：豆包手机销量与豆包 App 日活序列；Meta Muse 用户数；Apple Intelligence / Gemini 在手机上的 Agent 功能使用量。

已知可先抓取的页面（可能失效，失效就搜索）：

- https://openai.com/index/ （OpenAI 官方博客，找 dot 与 ChatGPT 用户数的发布）
- https://www.vellum.ai/blog/official-grok-bot-breakdown （Grok Bot 拆解，竞品所写）
- https://x.ai/news （xAI 官方新闻）
- https://www.stepfun.com/ （阶跃官网）

输出：`notes/G1-Agent产品增长.md`。

## 模块 G2：Agent 使用量的宏观增长曲线

问题：

1. **token 用量时间序列**：Google 每月处理 token（已知 2024-04 约 9.7 万亿、2025-05 约 480 万亿、2025-07 约 980 万亿、2025-10 约 1300 万亿、2026-05 约 3200 万亿，请核实并补 2026 下半年的点）；字节豆包日均 token（已知 2026-03 超 120 万亿、2026-06 超 180 万亿，请补 2024–2025 的点和 2026 下半年的点）；OpenRouter 的周 token 用量及其中 Agent / 工具调用占比的变化。
2. **Agent 专属指标**：支付宝 AI 付或智能体交易笔数的时间序列（已知累计 3 亿笔，请找时间点）；MCP 服务器数量或下载量的增长；A2A 协议的采用方数量；企业 Agent 部署数（如 Microsoft、Salesforce 的披露）。
3. **市场规模预测**：IDC、Gartner、Counterpoint、中国信通院等对「AI Agent 市场」或「端侧 AI / GenAI 手机」出货与渗透率的预测（给出年份序列，注明预测口径）。
4. **反面证据**：有无数据表明 Agent 使用增长放缓、留存差或付费转化低（例如二手分析认为 Google token 月增量在放缓）。有就写，汇报需要知道风险。

已知可先抓取的页面：

- https://blog.google/technology/ai/ （Google I/O 与财报中 token 数据的转述）
- https://openrouter.ai/rankings （OpenRouter 用量排行）
- https://www.volcengine.com/ （火山引擎，豆包 token 数据）

输出：`notes/G2-Agent宏观增长曲线.md`。

## 输出格式（两个模块相同）

```
# G? 标题
> 日期、预算使用情况、未核实项数量

## 1. 结论摘要（不超过 6 条，每条带等级）
## 2. 证据表（指标 | 日期 | 数值 | 单位与口径 | 来源 URL | 等级）
## 3. 可画曲线的时间序列（每条曲线一张小表：日期 | 数值；注明口径一致与否）
## 4. 找不到的数据（逐条写明搜过什么、为什么没有）
## 5. 参考文献（编号、标题、URL、访问日期）
```
